# Product sketches

Owner sketches guide layout and interaction. Each companion distinguishes what is
drawn, inferred wording, unresolved behavior, and existing spec requirements. Clean
wireframes aid reading; original sketches remain the design source. These artifacts
do not initiate implementation or add an approval process.

Start with the notes, then inspect the images as needed. Surface unclear details to
the owner for clarification now, rather than silently deferring them or inventing
extra screens, actions, or database fields. Record pending questions and incorporate
answers into the companion notes, wireframes, spec, and architecture as appropriate.
